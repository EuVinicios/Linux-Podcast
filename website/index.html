Seus podcasts em todos os lugares

Crie uma conta gratuita e sincronize os programas que você segue e onde parou em cada episódio, entre computadores e celulares. O PodFlow usa o protocolo aberto do gPodder, o mesmo de apps como AntennaPod, gPodder e Kasts.

  • gpodder.net: gratuito e de código aberto, conta em segundos.
  • Nextcloud: na sua própria nuvem, com o app GPodder Sync e login pelo navegador.
  • Servidor próprio: oPodSync, mygpo ou outro compatível.

A senha fica no chaveiro do sistema. Seus dados vão só para o servidor que você escolher.

Feito para o seu desktop

Instale em um minuto

Para Ubuntu 26.04 LTS ou mais recente e outras distribuições com GNOME 50.

Central de Aplicativos Snap

Procure por PodFlow na Central de Aplicativos do Ubuntu ou use o terminal:

sudo snap install podflow

Para guardar a senha da sincronização no chaveiro:
sudo snap connect podflow:password-manager-service

Pacote .deb Ubuntu

Leve (≈ 80 KB) e integrado ao sistema. Baixe na página de versões e instale:

sudo apt install ./podflow_*_all.deb

Baixar a versão mais recente →

Flatpak outras distros

Baixe o PodFlow.flatpak na página de versões e instale:

flatpak install --user ./PodFlow.flatpak

Perguntas frequentes

O PodFlow é gratuito?

Sim. É software livre (GPL-3.0 ou posterior), sem anúncios, sem assinatura e sem rastreamento.

Preciso criar uma conta?

Não. A conta só é necessária para sincronizar com outros aparelhos. Sem ela, tudo fica salvo neste computador.

Como sincronizo com o meu celular?

Crie uma conta no gpodder.net (ou use o seu Nextcloud) e entre com ela no PodFlow em Menu → Conta e sincronização. No Android, o AntennaPod sincroniza com as mesmas contas.

O PodFlow é da Apple?

Não. É um projeto independente que usa as APIs públicas de rankings e busca da Apple. “Apple Podcasts” é marca registrada da Apple Inc.

Onde ficam os meus dados?

No seu computador: em ~/.local/share/podflow (biblioteca e downloads) e ~/.cache/podflow (capas). Leia a política de privacidade.

Encontrei um problema. Como ajudo?

Abra um relato em GitHub Issues. Contribuições são bem-vindas: veja o guia de contribuição.
